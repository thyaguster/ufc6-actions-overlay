These original SVG files provide the overlay controller artwork. src/generate_controller_artwork.py converts their exact M/L/Q paths to GDI cubic paths; no fonts or hand-drawn substitutes are used. Whitespace around each icon is fitted to the target box while preserving aspect ratio. White face-button paths may be tinted to the existing console prompt colors; authored direction highlights are retained.
