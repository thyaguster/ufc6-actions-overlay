# Screenshot gallery — v0.9.26 preview

All overlay screenshots in this gallery use the same current appearance: **Amber**, **Rounded** boxes, **Xbox** controller icons, **18 px** font, **125%** UI scale and **Tall** window.

These images show the locally tested **v0.9.26 development build**. The latest published binary release remains **v0.9.18**; this screenshot refresh does not publish a new installer.

Full game-window images are actual **2560 × 1440** captures from the installed overlay in UFC 6, with the UI included by its screenshot setting. Isolated page previews use the current native overlay renderer and sample career/status values. Confirmation previews do not execute the actions shown. Windows setup, update and support tools retain their own application styling.
